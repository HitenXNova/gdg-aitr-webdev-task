## Section B: Bulk Certificate Generator
### Features Included
- **Upload Template:** Pick and upload custom certificate background images.
- **Import Names:** Upload `.csv` or `.xlsx` files containing participant names.
- **Live Preview:** Adjust text positions, font size, and color in real time.
- **Export Options:** Download individual or batch certificates.

### Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
